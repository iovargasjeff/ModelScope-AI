# Published data snapshot

This directory contains the public ModelVerdict leaderboard JSON snapshot, its normalized CSV, and metadata from the source run. The data is distributed under CC BY 4.0; retain attribution to [ModelVerdict](https://modelverdict.ai) when reusing it. See the [open-data terms](https://modelverdict.ai/en/data/) and [methodology](https://modelverdict.ai/en/methodology/).

Refresh the files with `python scripts/fetch_data.py`. The script validates the source license and payload before replacing the previous snapshot.
